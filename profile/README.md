## บริการ

| บริการ | ทำอะไร | สถานะ |
|---|---|---|
| **MyPCU Account** · `iam.mypcu.app` | บัญชีกลาง ลงชื่อเข้าใช้ครั้งเดียวด้วย OpenID Connect รองรับ ThaID, MOPH Provider ID, Google, LINE และ Passkey · บัญชีเดียวทำงานได้หลายหน่วยบริการ | 🧪 ต้นแบบ |
| **MyAssets** · `assets.mypcu.app` | ทะเบียนครุภัณฑ์และวัสดุของหน่วยบริการ ตรวจนับ โอนย้าย และรายงาน | 🚧 กำลังพัฒนา |
| **MyAssets Center** · `assets-center.mypcu.app` | ศูนย์กลางออกใบอนุญาตและตั้งค่าการใช้งานให้แต่ละหน่วย | 🚧 กำลังพัฒนา |

## หลักการ

- **บัญชีเดียว**: เข้าสู่ระบบครั้งเดียว ใช้ได้กับทุกแอปในเครือข่าย
- **หลายหน่วยในบัญชีเดียว**: เจ้าหน้าที่ที่ดูแลหลายหน่วยสลับหน่วยได้โดยไม่ต้องมีหลายบัญชี สิทธิ์เปลี่ยนตามหน่วยที่เลือก
- **ข้อมูลส่วนบุคคลเข้ารหัส**: เลขบัตรประชาชนและข้อมูลอ่อนไหวเข้ารหัสก่อนเก็บ
- **เชื่อมต่อแบบมาตรฐาน**: แอปภายนอกที่อยากใช้บัญชี MyPCU ลงทะเบียนเป็น OAuth client ได้

## เทคโนโลยี
